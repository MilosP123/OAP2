# OAP2

Glavni istraživački projekat je u **[Projekat/](Projekat/README.md)**:
uticaj okruženja galaksija na AGN aktivnost u TNG100-1, snapshot 99.

Uputstva za podatke, pokretanje, metodologiju i testove nalaze se u tom direktorijumu.
GitHub Actions proverava AGN projekat nad jasno označenim sintetičkim podacima.
Za naučne rezultate potreban je stvarni TNG katalog; nije priložen u repozitorijumu.

Notebook-ovi `Drugi_domaci_MP.ipynb`, `Treci_domaci_MP.ipynb` i `Untitled3.ipynb`
u korenu su odvojeni domaći zadaci, nisu deo AGN analize niti AGN CI provere.
`Treci_domaci_MP.ipynb` koristi priloženi `gr.dat`; `Untitled3.ipynb` zahteva
`sunspot.npz` koji ovde nije priložen, a drugi domaći koristi NASA mrežni servis.
